# Reference intensity

Provides the standard reference intensity level.

## Usage

``` r
referenceIntensity(output.unit = "watt_cm2", unit)
```

## Arguments

- output.unit:

  Unit to return, "watt_cm2"

- unit:

  Deprecated, use output.unit instead.

## Value

The reference sound intensity, in the unit specified.

## Examples

``` r
ri <- referenceIntensity()
```
